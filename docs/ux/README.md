# UX Prototype

This folder contains the initial UX prototype for the project **“Design and Development of a Web-Based Car Service Booking and Management System.”**

## Purpose

The prototype demonstrates the main user flows and role-specific interfaces for:

- Customer
- Mechanic
- Admin

## Customer Flow

The primary customer flow is:

`Login → Dashboard → My Cars → Services → Book Service → Select Time → Confirm Booking → My Bookings → Service History`

Included screens:

- `01-login.svg`
- `02-customer-dashboard.svg`
- `03-my-cars.svg`
- `04-services.svg`
- `05-book-service.svg`
- `06-available-slots.svg`
- `07-booking-confirmation.svg`
- `08-my-bookings.svg`
- `09-service-history.svg`

## Mechanic Interface

`10-mechanic-dashboard.svg`

The mechanic interface demonstrates:

- assigned jobs;
- daily schedule information;
- vehicle and service details;
- service status updates;
- mechanic comments;
- service completion.

## Admin Interface

`11-admin-dashboard.svg`

The admin interface demonstrates:

- booking statistics;
- booking management;
- mechanic assignment;
- service management;
- user and mechanic management;
- workshop schedule access.

`ux-prototype-overview.svg`

## Notes

The prototype is an initial pre-development UX design. It is intended to validate the required screens and user flows before frontend implementation.

The final React application may refine visual details while preserving the core workflows represented in this prototype.
